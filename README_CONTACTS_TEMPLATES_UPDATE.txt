Contacts and Message Templates Update

This update adds:
- Contacts management page.
- Message templates management page.
- Default message templates for email and WhatsApp.
- Contact and template selectors in email compose page.
- Contact and template selectors in WhatsApp compose page.
- Permissions for contacts and templates.
- Optional contact/template references in email and WhatsApp logs.

Install:
1. Extract files into the Laravel project root.
2. Run: php artisan migrate
3. Run: php scripts/check_contacts_templates_update.php
4. Clear caches and run the server.
