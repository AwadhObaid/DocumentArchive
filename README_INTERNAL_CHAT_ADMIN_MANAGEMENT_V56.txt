# V56 - Internal Chat Admin Management

هذا التحديث يضيف داخل صفحة الإعدادات قسمًا إداريًا باسم "إدارة الدردشة الداخلية" ويشمل:

- إنشاء نسخة احتياطية للدردشات الداخلية بصيغة JSON.
- استعادة نسخة احتياطية للدردشات.
- استعادة الدردشات المحذوفة أو المؤرشفة ظاهريًا.
- تفريغ الدردشات المحذوفة نهائيًا بطريقة آمنة.
- إنشاء نسخة احتياطية تلقائية قبل التفريغ النهائي.
- صلاحيات مستقلة للمدير.
- تسجيل العمليات في سجل النشاط.

## الصلاحيات المضافة

- internal_chat.backup
- internal_chat.restore_backup
- internal_chat.restore_deleted
- internal_chat.force_delete

## ملاحظات أمان

التفريغ النهائي لا يحذف الدردشات النشطة، بل يحذف فقط المحادثات التي أصبحت محذوفة أو ممسوحة لدى جميع المشاركين.

لا يحتاج التحديث إلى migrate ولا npm run build.
