DocumentArchive - Internal Chat Volume & User Spacing Fix V36
============================================================

هذا التحديث يعالج نقطتين في الدردشة الداخلية العائمة:

1) إضافة التحكم في مستوى صوت نغمة تنبيه الدردشة من الإعدادات.
   - الإعداد الجديد: internal_chat_sound_volume
   - القيمة الافتراضية: 85%
   - المدى: من 0% إلى 100%
   - النغمة أصبحت أوضح وأقوى، ومستواها يقرأ من إعدادات النظام.

2) إصلاح تلاصق اسم المستخدم ومعاينة آخر رسالة في قائمة المستخدمين.
   - فصل اسم المستخدم ومعاينة الرسالة في سطرين واضحين.
   - منع ضغط النص داخل صف المستخدم.
   - تحسين عرض الأسماء العربية والإنجليزية داخل القائمة.

طريقة التركيب:
---------------
فك الضغط داخل مشروع Laravel مع الاستبدال، ثم نفذ:

php scripts/check_internal_chat_volume_spacing_fix_v36.php
php artisan optimize:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear
php artisan config:clear
php artisan serve

بعد التشغيل:
-------------
1. افتح الإعدادات.
2. ابحث عن قسم: إعدادات الدردشة الداخلية العائمة.
3. عدل: مستوى صوت تنبيه الدردشة.
4. احفظ الإعدادات.
5. افتح النظام واضغط Ctrl + F5.
6. جرّب وصول رسالة جديدة من مستخدم آخر.

ملاحظات:
--------
- لا يحتاج Migration.
- Chrome/Edge يحتاجان أول تفاعل من المستخدم مع الصفحة قبل السماح بتشغيل الصوت.
- زر الكتم داخل نافذة الدردشة ما زال يعمل محلياً لكل جهاز.
