# V63 - Leave Calculator Page

هذا التحديث يضيف صفحة حاسبة الإجازات داخل النظام.

## المسار

/tools/leave-calculator

## اسم الرابط

tools.leave-calculator.index

## ماذا تضيف الصفحة؟

- اختيار تاريخ البداية والنهاية.
- حساب السنوات والشهور والأيام.
- حساب إجمالي الأيام.
- حساب أيام عطلة نهاية الأسبوع، افتراضيًا الجمعة والسبت.
- إدخال عطلات رسمية اختيارية بصيغة YYYY-MM-DD.
- حساب صافي الأيام بدون عطل.
- خيار احتساب يوم البداية ضمن الإجازة.

## ملاحظات

- لا يحتاج migration.
- لا يحتاج npm run build.
- الصفحة تعتمد على JavaScript عادي داخل public/js.
- تم إضافة صلاحية جديدة: tools.leave_calculator.
- المدير يملك الصلاحية تلقائيًا إذا كانت صلاحياته *.
