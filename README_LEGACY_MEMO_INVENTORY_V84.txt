DocumentArchive - Legacy Memo Inventory V84
================================================

الغرض
-----
هذه المرحلة تفحص مجلد المذكرات القديمة على Server-1 قبل الاستيراد الفعلي.

ما تقوم به V84
--------------
- فحص مجلد واحد مع خيار فحص المجلدات الفرعية.
- دعم PDF والصور وWord وExcel.
- حساب بصمة SHA-256.
- كشف تكرار المحتوى داخل المجلد.
- كشف المرفقات الموجودة مسبقًا في وحدة المذكرات.
- اقتراح تاريخ المذكرة من اسم الملف، وإلا من تاريخ تعديل الملف.
- اقتراح موضوع من اسم الملف أو المجلد.
- اقتراح أرقام داخلية غير محجوزة.
- حفظ تقرير تفصيلي قابل للبحث والتصفية.
- تصحيح بداية ترقيم المذكرات إلى 2600000.

ما لا تقوم به V84
-----------------
- لا تنشئ أي مذكرة.
- لا تنسخ أي ملف.
- لا تعدل أو تحذف ملفات Server-1.
- لا تحجز الأرقام المقترحة.
- لا تنفذ الاستيراد النهائي؛ ذلك سيكون في V84.1 بعد مراجعة التقرير.

ملاحظة ترقيم مهمة
------------------
- الرقم الأساسي المعتمد: 2600000.
- المذكرات الموجودة لا يُعاد ترقيمها.
- إذا كانت هناك مذكرات قائمة من 2600001 فما بعد، يحافظ النظام عليها ويولد الرقم التالي الآمن.
- إذا لم توجد مذكرات، يكون أول رقم 2600000.

التركيب
-------
php scripts/apply_legacy_memo_inventory_v84.php
php artisan migrate

php artisan optimize:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear
php artisan config:clear

php scripts/check_legacy_memo_inventory_v84.php

التجربة
-------
1. افتح صفحة المذكرات.
2. اضغط "استيراد المذكرات القديمة".
3. أدخل مسار مجلد المذكرات على Server-1.
4. ابدأ الفحص التجريبي.
5. راجع الجاهز والمكرر والملفات التي تحتاج مراجعة.

لا يحتاج التحديث إلى npm run build.
