تحديث نظام الأرشفة - مواضيع الكتب + المذكرات
================================================

محتويات التحديث:
1) صفحة مواضيع الكتب.
2) اختيار موضوع الكتاب من قائمة في صفحة إضافة/تعديل الكتاب.
3) صفحة مستقلة للمذكرات.
4) ترقيم المذكرات يبدأ من 2600001 ثم 2600002.
5) أرشفة مرفقات المذكرات داخل النظام.
6) معاينة مرفقات المذكرات داخل النظام/المتصفح بدون إجبار المستخدم على التنزيل.

مهم:
- زر "معاينة داخل النظام" يعرض PDF والصور داخل صفحة النظام.
- زر "فتح في المتصفح" يفتح الملف inline في تبويب جديد.
- زر "تحميل اختياري" موجود عند الحاجة فقط ولا يتم تنزيل الملف تلقائيًا.

طريقة التركيب على جهاز التطوير:
1) فك الضغط داخل جذر المشروع مع الاستبدال:
   E:\LaravelProjects\DocumentArchive

2) نفّذ:
   cd E:\LaravelProjects\DocumentArchive
   php artisan migrate
   php scripts/check_memos_book_subjects_update.php
   php artisan optimize:clear
   php artisan route:clear
   php artisan view:clear
   php artisan cache:clear
   php artisan config:clear
   php artisan serve

صفحات الاختبار:
- http://127.0.0.1:8000/book-subjects
- http://127.0.0.1:8000/documents/create
- http://127.0.0.1:8000/memos
- http://127.0.0.1:8000/memos/create

اختبار المرفقات:
1) أضف مذكرة مع مرفق PDF.
2) افتح صفحة عرض المذكرة.
3) يجب أن تظهر معاينة المرفق داخل النظام.
4) من قائمة المرفقات جرّب "معاينة داخل النظام".
5) لا يجب أن يجبرك المتصفح على التنزيل إلا عند الضغط على "تحميل اختياري".

بعد نجاح التجربة:
- اعمل commit ثم push.
- على السيرفر نفّذ git pull ثم php artisan migrate والتنظيف.


V3 - عرض مرفقات المذكرات بنفس طريقة الكتب
-----------------------------------------
- تم تعديل صفحة عرض المذكرة لتعرض المرفقات في جدول بنفس طريقة صفحة عرض الكتاب.
- تم توحيد أزرار المرفقات إلى: معاينة / تنزيل.
- تم تعديل صفحة معاينة مرفق المذكرة لتستخدم نفس آلية معاينة مرفقات الكتب:
  JSON data endpoint + Blob preview + فتح في تبويب جديد + طباعة المرفق.
- تمت إضافة route جديد:
  memos.attachments.data
- التنزيل لا يتم إجبارياً؛ المعاينة تتم داخل النظام، والتنزيل زر اختياري.
