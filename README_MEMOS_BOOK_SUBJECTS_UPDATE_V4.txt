تحديث V4 - إصلاح تمدد صفحة المذكرات خارج النطاق

المشكلة:
- جدول المذكرات كان يدفع الصفحة كاملة للتمدد أفقياً، فيظهر السكرول على الصفحة بدل جدول المذكرات.

الإصلاح:
- ضبط الحاويات داخل صفحة المذكرات بـ min-width:0 و max-width:100%.
- حصر التمرير الأفقي داخل .memos-table-scroll فقط.
- إبقاء جدول المذكرات بعرض أدنى مناسب، مع سكرول داخلي للجدول.

طريقة التركيب:
1) فك الضغط داخل جذر المشروع مع الاستبدال.
2) نفّذ:
   php artisan optimize:clear
   php artisan route:clear
   php artisan view:clear
   php artisan cache:clear
   php artisan config:clear
3) أعد تحميل صفحة المذكرات بـ Ctrl + F5.

لا يحتوي هذا التحديث على migrations جديدة.
