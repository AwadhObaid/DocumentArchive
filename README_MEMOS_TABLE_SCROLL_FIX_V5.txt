DocumentArchive - Memos Table Scroll Fix V5

هذا الإصلاح يعالج اختفاء السكرول الأفقي في صفحة المذكرات بعد V4.

التعديل:
- جعل السكرول الأفقي داخل جدول المذكرات فقط.
- منع خروج الصفحة كاملة عن النطاق.
- استخدام نفس منطق صفحة الكتب: wrapper باتجاه LTR والجدول RTL.
- إظهار scrollbar واضح أسفل الجدول.

طريقة التركيب:
1) فك الضغط داخل جذر المشروع مع الاستبدال.
2) نفذ أوامر تنظيف Laravel.
3) افتح صفحة /memos واضغط Ctrl+F5.

لا توجد migrations في هذا الإصلاح.
