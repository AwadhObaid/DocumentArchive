تحديث الأمان ونسخة الهاتف لايت وأيقونة الأرشفة
================================================

يضيف هذا التحديث:
1) تسجيل خروج تلقائي عند عدم النشاط مع مدة قابلة للتعديل من صفحة الإعدادات.
2) نسخة هاتف لايت للمعاينة فقط على الرابط /lite.
3) تنبيهات داخل نسخة الهاتف لايت بتحديث تلقائي حسب المدة المحددة في الإعدادات.
4) استبدال أيقونة تبويب المتصفح بأيقونة أرشفة بدلاً من أيقونة البيت.

روابط مهمة:
- الإعدادات: /settings
- نسخة الهاتف لايت: /lite
- كتب لايت: /lite/documents
- مذكرات لايت: /lite/memos
- إشعارات لايت: /lite/notifications

أوامر التركيب:
php artisan migrate
php scripts/check_security_lite_icon_update.php
php artisan optimize:clear
php artisan route:clear
php artisan view:clear
php artisan cache:clear
php artisan config:clear

ملاحظات:
- تسجيل الخروج التلقائي يكون غير مفعل افتراضياً حتى يفعله المدير من الإعدادات.
- نسخة الهاتف لايت للمعاينة فقط ولا تحتوي أزرار إضافة/تعديل/حذف.
- إشعارات الهاتف هنا داخل المتصفح وليست Push خارج المتصفح. تطوير Push حقيقي يحتاج مرحلة PWA/HTTPS لاحقاً.
- إذا بقيت أيقونة البيت ظاهرة في المتصفح، اضغط Ctrl+F5 أو امسح كاش الموقع لأن المتصفحات تخزن favicon بقوة.
